This package implements an experimental adaptation of:

Haosen Li et al., "Oracle Noise: Faster Semantic Spherical Alignment for Interpretable Latent Optimization", arXiv:2604.23540v1 (2026).
https://arxiv.org/abs/2604.23540

The optional spectral noise colorization was inspired by RES4LYF's Advanced Noise
and FractalNoiseGenerator. This package uses an independent implementation with
different user controls and applies the filter after Oracle optimization.
https://github.com/ClownsharkBatwing/RES4LYF

Model adapters follow ComfyUI's model implementations and interfaces at revision
6607f36b53c7b695b160ac5b52d595e9e3752a2d:
https://github.com/Comfy-Org/ComfyUI
